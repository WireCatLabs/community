# Getting help

Use the affected repository's README and issues for usage questions and bugs.
For WireCat CLI documentation, visit [wirecat.dev](https://wirecat.dev/).
Ask questions and talk with other users on [Discord](https://discord.gg/DebENqbRrJ) (English)
or [Telegram](https://t.me/wirecatdev) (Russian).
Keep credentials and private user data out of reports.

[Read the full policy](https://github.com/WireCatLabs/community/blob/main/support/README.md).
