# Getting help

For WireCat CLI installation and usage, start with
[wirecat.dev](https://wirecat.dev/) and the affected repository's README.
Other WireCat projects may provide their own documentation and support channels.

Search existing issues before opening a new one in the affected repository.
For a bug report, include the project and version, operating system, a minimal
reproduction, the expected result, and the actual result. Redact logs and use
synthetic examples. Never include tokens, credentials, session files, private
messages, or other personal data.

For a feature request, explain the task you want to accomplish and the limitation
you encounter. For a contribution, read
[CONTRIBUTING.md](https://github.com/WireCatLabs/community/blob/main/CONTRIBUTING.md).

Report suspected vulnerabilities privately under
[SECURITY.md](https://github.com/WireCatLabs/community/blob/main/SECURITY.md).
Public issues are not a security reporting channel.

Community support is provided as maintainers are available, without a guaranteed
response time. Any separately agreed commercial support terms govern that service.
