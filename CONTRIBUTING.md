# Contributing to WireCat

Read the shared guidelines for development, pull requests, contribution licensing,
and Developer Certificate of Origin sign-off. Sign off new contribution commits
with `git commit -s` after reading the DCO. Repository-specific instructions take
precedence.

[Read the full policy](https://github.com/WireCatLabs/community/blob/main/contributing/README.md).

Security audits follow the shared [security method](https://github.com/WireCatLabs/cli-testing/tree/main/docs/security) in cli-testing.
